Educational Security Laboratory Context:

Reflected Cross Site Scripting (XSS) occurs when an attacker crafts a malicious link containing executable code within a request parameter and tricks a victim into clicking it via phishing or disguised advertisements. When clicked, the application reads the query parameter from the URL and reflects it directly into the DOM without escaping.
